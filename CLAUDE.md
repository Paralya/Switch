# Switch

Minecraft datapack generated by StewBeet (beet) from `src/`. `build/` is the output: tracked in git, committed with the `src/` change that produced it, never edited by hand.

## Build

- `PYTHONUTF8=1 stewbeet build` (without it a cp1252 banner crashes the build). Never write an alternate beet config to skip a step.
- `copy_to_destination` in `beet.yml` uploads over SFTP to a server that is off. Check it before building.
- A refactor shows up as `git -c core.attributesFile=/dev/null --no-pager diff --text -- build/datapack/`, and only the intended restructuring may appear.

## Conventions

- Never write the `switch` namespace as a literal in a string. Use `{ns}` in an f-string, with `ns: str = Mem.ctx.project_id` as the first line of the function.
- Never touch `Mem.ctx` outside a function: the `stewbeet` CLI imports `src` modules before any context exists. Module-level constants stay namespace-relative (`LOAD_FILE = "advancements/_load"`, used as `f"{ns}:{LOAD_FILE}"`), or become functions.
- Every package directory under `src` has an `__init__.py`. Without it beet's module purge between pipeline passes fails with a `KeyError` on the namespace package.
- Duplicated mcfunction goes into one shared generated mcfunction that both sites call, with `$(arg)` macro lines when a few values differ. Shared mode logic lives in `src/datapack/modes/_common/main.py` and `src/datapack/modes/common.py`. A Python helper that writes a copy per mode is acceptable only when the output differs per call.
- Do not merge two independent game modes because they look alike. Extract only a truly shared concept.
- A function whose body is a single `function X` call is removed and its callers point at `X`. Exceptions: a fixed-name hook, or a function with no caller in the datapack because commands invoke it.
- Gamemode commands are `execute as <players> run gamemode <mode> @s`, so the "game mode updated" message stays silent.
- Commit messages are `type(scope): emoji Subject` with a short body, often in French. Keep the `Co-Authored-By` trailer the history uses.
- A `TODO` comment addressed to Claude is applied at once and the comment is removed.
